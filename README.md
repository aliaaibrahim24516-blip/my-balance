# MY BALANCE — ويب عربي

تطبيق شخصي بسيط بـ HTML وCSS وJavaScript فقط. لا خادم بيانات ولا حزم خارجية ولا تحليلات أو تتبع.

## الاستخدام

أربعة أقسام: اليوم، الأسبوع، المخزون والتسوق، والوزن. يبدأ بثماني عشرة وصفة منزلية مصرية وشامية وإيطالية تكفي أربعة أفراد، وخطة ٧ أيام × ٤ وجبات. البيانات الافتراضية عامة؛ لا توجد قياسات أو بيانات شخصية في المصادر.

- حصة مرنة برسمة الطبق، مع تفاصيل الكميات للأسرة وخطوات التحضير. الأطباق المختلطة والوجبات الخفيفة لها شرح مختلف؛ ليست الوصفات علاجًا أو خطة سعرات محسوبة أو ضمان نزول وزن.
- التبديل داخل نوع الوجبة لا يعيد ضبط الأسبوع. الأسبوع يبدأ بتاريخ قابل للاختيار.
- المشتريات = احتياج الوجبات التي لم تُطبخ − المخزون المؤكد، وبحد أدنى صفر.
- التخطيط لا يستهلك المخزون. تأكيد الطبخ يخصم مرة واحدة ويخصم المتاح فقط مع تنبيه إذا لم تتوفر الكمية. زر الشراء يضيف فقط النقص بعد تأكيده. الكميات المختلفة تعدل يدويًا.
- تدخل أسعار العبوات بالفلس مع حجم كل عبوة بوحدة الصنف، ويحسب التطبيق سعر الوحدة، مع تاريخ التحديث. الصنف غير المسعر يظهر غير معروف ويمنع اعتبار تقدير التكلفة كاملًا. صفر سعر معلوم فقط عند إدخاله عمدًا. الميزانية الافتراضية ٤٠ د.ك قابلة للتعديل؛ التكلفة تقريب لا يشمل أحجام عبوات المتجر أو عروضه، ولا تُختلق أسعار سوقية.
- تسجيل وزن اختياري بتاريخ، وتسجيل واحد لليوم مع تأكيد الاستبدال والحذف. النطاق الشهري يبدأ عند التفعيل الاختياري: ٣–٥ ثم ٢–٣ كجم، دون وعد أو حمية تلقائية؛ يمكن إخفاؤه. الشهر من تاريخ التفعيل مع مراعاة نهاية الشهر. بعد الشهر الثاني لا تمديد تلقائي.
- مفتاح الحمل يوقف الهدف والتقدم ويصفر بداية فترة الهدف. إيقاف المفتاح لاحقًا لا يستأنف هدفًا سابقًا دون تفعيل جديد.
- دعم ثابت قبل الأكل وبعد الإفراط ورسالة أمان عامة.

## التخزين والخصوصية

localStorage تحت المفتاح `my-balance-v1`. البيانات على نفس الجهاز والمتصفح واسم نطاق الموقع فقط، وليست في GitHub. مسح بيانات Safari أو التصفح الخاص أو تغيير رابط الاستضافة قد يفقدها. لا توجد مزامنة أو حماية بكلمة مرور أو تشفير تطبيقي. لا تستخدمي جهازًا مشتركًا للبيانات الحساسة.

تصدير JSON يتضمن الوزن وحالة الحمل والمخزون والأسعار والخطة. تحفظه المستخدمة في وجهة تنزيلاتها؛ هو غير مشفر ولا يجب رفعه إلى GitHub. الاستيراد محدود بـ٢ ميجابايت ويتحقق من الإصدار والأنواع والكميات والتواريخ ومعرفات الوصفات والمكونات قبل تأكيد الاستبدال. فشل القراءة لا يمسح البيانات. تجنب فتح أكثر من نسخة أثناء تعديلها؛ تصل تحديثات المتصفح الأخرى إلى العرض تلقائيًا.

يُحمّل المتصفح الملفات الثابتة من الاستضافة؛ قد تحتفظ جهة الاستضافة بسجلات طلبات الويب المعتادة. التطبيق نفسه لا يرسل البيانات المدخلة ولا يتصل بمتاجر أو أدوات تتبع. الرسوم والخطوط محلية بلا صور أو خطوط خارجية.

## التشغيل والنشر

يجب تقديم الملفات عبر HTTP أو HTTPS حتى يعمل تحميل `data/recipes.json`؛ فتح index.html مباشرة من تطبيق الملفات لا يكفي. لا توجد خطوة بناء. للنشر: اختاري Settings → Pages → Deploy from a branch → main → /(root)، ثم Save عندما تسمح خطة GitHub بذلك.

**حالة النشر** — الموقع منشور على [GitHub Pages](https://aliaaibrahim24516-blip.github.io/my-balance/) من الفرع الرئيسي في المستودع العام.

## التحقق

شُغلت اختبارات المنطق: `node --test tests/core.test.mjs` (١١ اختبارًا ناجحًا) وفحص تركيب ملفات JavaScript. جرى فحص محلي في متصفح بمقاس هاتف، وتسجيل وزن تجريبي وتصديره ثم استيراده، والتحقق من توقف الهدف عند الحمل. لم يجر اختبار على iPhone فعلي أو Safari؛ يلزم فحص تنزيل/استيراد JSON ولوحة الأرقام وVoiceOver هناك قبل الاعتماد اليومي.
